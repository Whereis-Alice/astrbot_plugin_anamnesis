# WebUI 管理

3.5.0 增加画像审核、证据和历史，时间范围调试及管理工作台。默认开关与操作说明见 [3.5.0 更新](/memorix-adaptations-3.5.0)。

3.5.18 的用户档案详情提供“暂停采用”：遇到把玩笑当真的旧事实，可暂停并填写原因，保留原文、证据与审核历史。暂停后该项不再注入对话，也不进入卡片有效事实预览；需要管理员明确确认“恢复采用”才恢复，编辑或再次自动提取不会解除暂停。操作精确定位当前会话、key、事实 ID 与修订号，过期页面需刷新。普通记忆仍是独立数据，如其摘要也误记了，应在记忆详情单独编辑或归档。

Anamnesis 使用 AstrBot 官方插件 Pages 提供管理界面，不需要额外启动 Web 服务。

## 入口

进入 AstrBot WebUI：

`插件 -> Anamnesis -> Pages -> dashboard`

建议 AstrBot 版本为 `4.24.2` 或更高。旧版本如果没有官方 Pages 能力，插件仍可运行，但管理页面可能不可用。

## 页面能力

| 区域 | 用途 |
| --- | --- |
| 记忆管理 | 查看与筛选记忆，编辑摘要、主题、关键事实、状态和重要性，批量删除，以及导入导出 |
| 用户档案 | 人物卡片展示昵称、账号、最近群名和有效事实预览；点击展开完整档案，按类别与聊天来源阅读、编辑、删除和审核 |
| 管理工作台 | 整次删除恢复、纠正预览与回滚、文件与目录导入任务、独立查询评测、事件和索引同步 |
| 召回调试 | 输入查询词与时间范围，选择模式、作用域和人格，观察实际召回结果与依据 |
| 图谱视图 | 浏览实体、关系和记忆之间的连接 |
| 系统状态 | 查看活跃、归档和删除记忆数量，以及图谱、原子、重要性和会话统计 |
| 提示词管理 | 按类别查看和编辑插件提示词，识别自定义状态，并恢复或载入默认内容 |

## 记忆详情与生命周期

3.5.17 起，用户档案默认展示人物卡片，桌面按宽度排列，手机使用单列。卡片显示真实的当前有效事实和最近已知见面时间，点击整卡展开完整阅读区，可返回人物列表；来源会话筛选与隔离说明收在「筛选与隔离设置」中。同一身份的不同聊天档案统一展示，存储和修改仍保留各自的会话归属。

“用户档案”页会显示全部已保存条目，仅适合有插件页面权限的管理员使用；档案功能关闭后仍可查看、修改和删除旧条目。目录显示最近已知群名，完整事实按类别与聊天来源分段；点击「查看 / 修改」可编辑标题、内容、类别、置信度和过期时间。默认隔离单位是平台、用户身份和 `unified_msg_origin` 聊天来源，不是每次 `/new` 产生的新对话记录。删除或修改档案条目不会删除关联的普通记忆。3.4.1 起，来源记忆已删除或不活跃的事实暂停注入，原档案条目仍保留在此页面供管理员检查。

3.4.2 起，目录的最近群名独立记录，聊天来源分段保留每条事实原有的会话出处；用户共享档案同样按来源会话分段。缺少账号的事件不建立档案，失效来源不占有效事实的注入名额。

- 编辑摘要、主题或关键事实时，插件会重建该记忆的 Embedding、BM25、图谱和原子等派生数据；只修改状态或重要性时不会无条件重建全部索引。
- 达到原文保留阈值的记忆会在详情中显示来源消息。至少包含两条来源消息时，可以调用 LLM 重新总结并替换原记忆。
- 将状态改为 `archived` 会把记忆移出正常召回索引但保留源文档；从 `archived` 改回 `active` 会重新生成 Embedding 和派生索引。
- 多选复选框支持当前列表中的批量删除；导出操作在有选中项时只导出选中的记忆。

::: warning
记忆列表的永久删除无法恢复。希望可恢复时，可归档或在管理工作台选择「移入恢复中心」。归档恢复需要可用的 Embedding Provider。
:::

## 提示词管理

提示词页面展示每个模板的用途、变量、默认或自定义状态。编辑器支持保存自定义内容、载入默认内容供修改，以及删除自定义覆盖并恢复内置默认值。标记为 JSON 的模板必须保持有效 JSON，否则保存会被拒绝。

自定义提示词存放在插件数据目录，不会修改仓库内置模板。升级插件时自定义内容会继续保留。

## 图谱视图适合看什么？

图谱不是为了替代表格，而是帮助你发现记忆之间的结构关系：

| 观察点 | 示例 |
| --- | --- |
| 高频实体 | 用户、项目、地点、群聊主题 |
| 稳定关系 | “某人喜欢某事”“项目依赖某技术” |
| 跨记忆连接 | 多次对话中重复出现的同一实体 |
| 过期风险 | 很久没有被访问的低重要性关系 |

::: tip
图谱页默认展示最近记忆的受限子图（节点/边受上限约束），点击「全量图谱」按钮才会加载全部节点与关系。
:::

3.5.17 修复官方接口脚本晚于页面主程序加载时的初始化问题。打开页面会自动加载受限概览和统计，无需先点右上角按钮；连接失败时侧栏仍可切换，页面上方提供「重新连接」。更新后请重载插件，并关闭再打开 dashboard；旧资源仍被缓存时强制刷新浏览器。

::: tip
WebUI 的操作会复用插件运行时的 MemoryEngine 和 GraphStore，不会绕过后端数据安全逻辑。
:::

后台索引检查和大规模重建进度当前通过 `/anam status` 查看；状态含义和故障处理见[命令速查](/commands#索引维护状态)。

## 记忆迁移

记忆页支持 JSON 和 CSV：

- 未选择记忆时导出全部；选择当前页中的记忆后只导出所选项。
- 原生 JSON 和 CSV 可完整往返摘要、作用域、人格、结构化元数据、已保留原文和事实原子的生命周期；过期、遗忘或替代事实不会因导入重新生效。
- 外部 JSON 可使用 `content`、`text`、`summary` 或 `memory` 作为摘要字段，也可使用 `memories`、`long_term_memories`、`short_term_memories` 和按会话 ID 组织的多轮消息。
- 导入先执行预检；默认按“摘要内容 + 会话 ID + 人格 ID”跳过重复项，也可显式允许重复。
- 只有多轮原始消息但没有摘要时，每个导入项会调用一次 LLM 生成摘要；成功导入会走当前配置的完整写入链路，重新生成 Embedding，并在相应功能已启用且数据满足条件时生成图和原子索引。

导入记录先完成原文和生命周期保存再恢复原状态；失败时清理暂存记录。历史消息 ID、修订号和窗口位置保存为导入出处，不参与当前聊天的消息回退。归档记录保留在管理页，恢复时沿用原始事实期限。

单个文件上限为 50 MiB、10,000 条记忆。导出文件可能包含敏感原文，应按数据库备份同等标准保管。
