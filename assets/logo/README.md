# astrbot_plugin_anamnesis — logo

一个由图节点构成的向内漏斗（三臂漩流），汇聚到唯一的暖色核心。

| 元素 | 语义 |
| --- | --- |
| 节点 + 连线 | 知识图记忆：实体节点与关系边 |
| 三条同旋向内收束的臂 | recall / anamnesis：沿线索回溯，回忆起灵魂本已知晓之事 |
| 外端细、小、半透明 | decay / forget：边缘记忆衰减至消失 |
| 向内递增的粗细、尺寸、亮度 | reflect / consolidate：反思与整合使记忆变得更强 |
| 中心琥珀色圆盘（全图唯一暖色） | 被召回、已固存的记忆本身 |

## 为何是“短扫角 + 三臂”

徒形是圆形，所以它自带一个强烈的同心参考系。一条链只有在**螺旋升角（pitch）足够大**
时才会被读成螺旋：pitch = atan(径向行程 / 弧长)。早期稿用 260～320° 扫完约 130 px
的半径差，pitch 约 13°，几乎平行于轮廓——结果全部读成“原子 / 行星轨道”。
定稿每条臂只用 120° 走完同样的半径差，pitch 约 27°，且三臂之间留出大片空扇形，
使得徒形上任何一条半径射线都不会穿过两层螺圈，因此不会误读成同心环。

## 技术路线

纯程序化绘制：Python + numpy + Pillow。所有图形都是解析的反锯齿覆盖率掩码，
在 4× 超采样（2048²）下合成后 LANCZOS 降到 512，最后在 512 上套圆形 alpha。
确定性输出，改参数重跑即可。

```powershell
cd path\to\astrbot_plugin_anamnesis
python assets/logo/generate_logo.py
```

`generate_logo.py` 会把 `VARIANTS` 里每一稿都渲染到 `drafts/`，再把 `FINAL`
指向的那一稿写成仓库根的 `logo.png` 和这里的 512 / 128 / 64 三个尺寸。
当前定稿：`a2-vortex`。

## 规格与验收

- 512×512 PNG（RGBA，徒形以外透明），约 80 KB，限额 200 KB
- 徒形半径 240，四边各留 16 px 安全边；最外层节点边缘到徒形边缘还有 27 px
- 配色：徒形 `#1d3b36` → `#142c29`，轮廓 `#5f9f92`，冷色斜坡 `#3b7a6f` → `#a6f6d8`，核心 `#e8b45f`
- 无文字、无字母、无写实质感、无 3D 高光（核心是正平的实色圆盘）
- 64×​64 可辨识关卡：9 个节点、最小节点直径 13 px（512 下）、核心直径 92 px（缩到 64 后约 11.5 px）

## 目录

- `generate_logo.py` — 唯一源文件（改这个）
- `logo-512.png` / `logo-128.png` / `logo-64.png` — 定稿多尺寸导出
- `drafts/` — 全部候选稿（每次重跑都会刷新）与 `_cmp64.png` 64 px 对比图
